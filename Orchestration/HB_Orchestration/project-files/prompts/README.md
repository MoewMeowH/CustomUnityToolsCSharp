# 외부 에이전트 실수 목록 (모델별 프롬프트 덧붙임)

이 폴더의 `<역할>/<에이전트 이름>.md`가 그 (역할, 에이전트)의 시스템 프롬프트 맨 끝에 `## 모델별 덧붙임`으로 붙는다.
그 역할 · 모델이 자주 하는 실수와 버릇을 적는 자리다. 자세한 규칙은 HB_Orchestration README "모델별 덧붙임".

* 서버는 appsettings `Orchestration:PromptsPath`로 이 폴더를 읽는다 (비우면 modes.json 옆 `prompts/`). Unity 프로젝트로 동기화되지 않는다.
* HTML 주석(`<!-- -->`)은 보내지 않는다. 주석을 뺀 본문이 비면 붙이지 않는다 — 기본 파일은 서식 안내 주석뿐이다. 주석 안에 주석을 넣으면 실행이 거절된다.
* 한 줄에 하나, 에이전트에게 하는 말로 쓴다. 날짜 · 출처(runId · 지적 ID)는 줄 끝 HTML 주석으로 단다.
* 본문에 `<!--` · `-->` 문자열을 쓰지 않는다 (ASCII 화살표 `-->` 포함 — 화살표는 `→`). 주석 짝이 안 맞는 것으로 보고 실행을 거절한다.
* 골든 사례가 있는 역할에 넣었으면 골든 1건으로 확인한다.
* 새 (역할, 에이전트) 쌍을 modes.json에 넣으면 같은 서식으로 파일을 만든다.
* 리뷰 기준(코드에서 찾을 문제)은 여기가 아니라 `REVIEW_GUIDELINES.md`에 둔다.
* 이 README는 덧붙임으로 읽히지 않는다 (하위 폴더의 .md만 읽음).
